The itchwhy

When working with tlc-spec-driven, each feature starts on a new branch:

git checkout -b m2/feature-slug
  • opencode auto-names sessions: "Passenger and payments implementation" or worse, generic slugs.
  • You can't tell which session belongs to which branch.
  • Idea: the session should just be named the branch — and know the branch conventions.

Why the plugin, not the DBdecided

Renaming through the running server is the official path:

  • No cache fights — direct writes get clobbered by the server's in-memory rows and auto-title.
  • TUI updates live — no restart.
  • Version-safe — no dependency on the internal schema.
  • Extensible — the same plugin can add tools and conventions, not just a rename.
Plugin mechanics — confirmedverified

Checked against installed @opencode-ai/plugin@1.18.15 + SDK:

Hook — fires after every tool call, gives us the session

"tool.execute.after": async ({ tool, sessionID, args }) => {
  if (tool === "bash" && /git (checkout -b|switch -c)/.test(args.command)) {
    const branch = args.command.match(/([^\s]+)$/)[1];
    await client.session.update({ path: { id: sessionID },
                                  body: { title: branch } });
  }
}

sessionID and client.session.update both verified in the type defs.

The one gotchacareful

opencode emits vcs.branch.updated on any branch change (including when you type the command in the terminal)…

…but that event carries no sessionID.

Consequence

  • The rename hook reliably catches agent-run git checkout -b — exactly the tlc-spec-driven flow.
  • Terminal-typed branch switches are not renameable this way.
The plugin — full scopevision

Not just a renamer — a whole plugin centered on tlc-spec-driven.

1 · Convention holder

Parameters in .opencode/tlc.jsonc (single source). Conventions removed from AGENTS.md — the how-to lives in the companion skill.

2 · tlc_branch tool

Built. Generates / validates m{N}/{feature-slug}; the skill tells the agent to call it.

3 · Session rename

Built. tool.execute.after → session title = branch, gated to sessions that loaded a tlc skill.

4 · Worktree tool

Scaffolded. Explicit tlc_worktree tool, sibling dir, session fork. Auto-spawn intentionally deferred.

Worktree automation — shape & decisionslocked
